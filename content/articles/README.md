# Articles (content projects)

One directory per article, each with an explicit name: each article holds its own tapes/samples (if any), build output, and optional platform subdirs (mastodon, linkedin, twitter).

- **`one_to_rule/`** – Hero video + linked-post assets; includes `tapes/`, samples, and single `output/` for all GIFs and video. The hero build script **`one_to_rule/generate_one_to_rule_video.sh`** lives in that folder (not under `content/scripts/`) and is tracked in git. See [one_to_rule/README.md](one_to_rule/README.md).
