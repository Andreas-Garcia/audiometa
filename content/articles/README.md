# Articles (content projects)

One directory per article, each with an explicit name: each article holds its own tapes/samples (if any), build output, and optional platform subdirs (mastodon, linkedin, twitter).

- **`one_to_rule/`** – Hero video + linked-post assets; includes `tapes/`, samples, and single `output/` for all GIFs and video. See [one_to_rule/README.md](one_to_rule/README.md).
